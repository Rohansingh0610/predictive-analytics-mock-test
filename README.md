# Predictive Analytics & Machine Learning — Mock Test (Part 2)

An interactive, responsive web-based mock test platform designed for studying and practicing Predictive Analytics and Machine Learning concepts.

## 🚀 Features

- **Interactive Quiz Interface**: Multiple-choice questions with real-time progress tracking.
- **Detailed Review Mode**: Review all questions with explanations, correct answers, and status filters (All, Correct, Incorrect, Unanswered).
- **Randomize & Shuffle**: Reshuffle question and option order for repeatable practice.
- **Persistent State**: Keeps track of current progress and answers locally.
- **Clean Aesthetic**: Tailored typography, sleek responsive layout, and mobile-friendly styling.

## 🛠️ Tech Stack

- HTML5
- Vanilla CSS3 (Custom design tokens & responsive components)
- Vanilla JavaScript

## 🌐 Deploy to Vercel

This repository is ready for instant deployment on [Vercel](https://vercel.com):

1. Go to [vercel.com/new](https://vercel.com/new).
2. Select and import the `predictive-analytics-mock-test` repository.
3. Keep default settings (Framework preset: `Other`, Root Directory: `./`).
4. Click **Deploy**.
